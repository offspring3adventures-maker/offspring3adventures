# Offspring Adventures

Travel agency website for Offspring Adventures.

## Current MVP

- Responsive homepage
- Trips overview
- Beach, cruise, all-inclusive, family, couples and international travel sections
- About/travel advisor section
- Visitor inquiry form
- Mobile-friendly navigation and layout

## Next launch steps

1. Connect the inquiry form to the production backend/dashboard.
2. Add real contact details and legal/privacy pages.
3. Add approved photography and branding assets.
4. Connect the production domain.
5. Run mobile, accessibility, form, SEO and deployment checks.

The current inquiry form uses browser storage as a temporary MVP placeholder; it does not yet send inquiries to the travel advisor dashboard.
